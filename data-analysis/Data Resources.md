# Data Resources

Starting points for finding datasets for analysis and practice. Evaluate each dataset using [[Data Collection and Quality#Evaluating Data Sources|ROCCC]], its relevance to the question, and its [[Metadata and Governance#Metadata for Analysis|metadata]].

## General Catalogs and Platforms

| Resource | Useful for |
|---|---|
| [Data.gov](https://data.gov/) | U.S. government datasets across many topics. |
| [U.S. Census Bureau](https://www.census.gov/data.html) | U.S. population, demographic, and economic data. |
| [Google Dataset Search](https://datasetsearch.research.google.com/) | Finding datasets published across the web. |
| [Google Cloud Public Datasets](https://cloud.google.com/datasets) | Public datasets hosted in Google Cloud. |
| [BigQuery public datasets](https://cloud.google.com/bigquery/public-data) | Exploring hosted datasets using SQL; query costs may apply. |
| [Kaggle Datasets](https://www.kaggle.com/datasets) | Community-published datasets for exploration, practice, and projects. |
| [Open Data Network](https://www.opendatanetwork.com/) | Discovering public datasets from different organizations. Availability unverified (24 October 2026). |

## Resources by Topic

| Topic | Resource | Useful for |
|---|---|---|
| **Health** | [WHO data collections](https://www.who.int/data/collections) | International health and well-being data. |
| **Climate and environment** | [NOAA / NCEI products](https://www.ncei.noaa.gov/products) | Weather, climate, ocean, and other environmental records. |
| **Employment** | [BLS Current Population Survey tables](https://www.bls.gov/cps/tables.htm) | U.S. employment, unemployment, and labor-force statistics. |
| **Policing** | [Stanford Open Policing Project](https://openpolicing.stanford.edu/) | Standardized records of vehicle and pedestrian stops from participating U.S. agencies. |

## Choosing and Reusing a Dataset

Check the original publisher, definitions, collection methods, coverage, update dates, license, and access or computing costs. Public availability and reuse permissions are separate considerations.

A catalog may link to data hosted elsewhere. Confirm the format and size suit your tools, and record the version or retrieval date so the analysis can be reproduced.
