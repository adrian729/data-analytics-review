This is the Analyze phase: taking data that has already been collected and cleaned and making it answer the original question. It starts with the two organizing actions — sorting and filtering — done first with spreadsheet tools, then with SQL queries on data too large for a sheet. Then comes formatting: converting data between types, validating what gets entered, and combining separate datasets so they can be analyzed as one, whether by importing and merging text strings in a spreadsheet or by manipulating strings in SQL.

The second half is where the answers actually come from. You'll aggregate separate pieces into a single view — VLOOKUP and JOINs pulling matching rows from different tables together, subqueries nesting one query inside another — and then run the calculations themselves: percentages and profit margins, conditional and composite functions, pivot tables, and SQL arithmetic with GROUP BY. It closes the way course 4 did, by trusting nothing blindly: validating data as you calculate and building temporary tables so results can be checked and reused without touching the source.
