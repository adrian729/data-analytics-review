Spreadsheets are a key data analytics tool, and their usefulness maps cleanly onto each phase of the [data life cycle](/glossary#data-life-cycle):

- **Plan** — set organizational standards before anyone works in a spreadsheet: cell formatting, which headings to highlight, a color scheme, how data points are ordered. This improves communication, consistency, and efficiency.
- **Capture** — connect a spreadsheet to another data source, like an online survey tool or a database, so it updates automatically and stays current. Some of that captured data may itself be [open data](/glossary#open-data) — data available to the public, like a government dataset.
- **Manage** — store, organize, and update information using [filtering](/glossary#filtering) (show only what meets a criteria) and [sorting](/glossary#sorting) (arrange it into a meaningful order); decide who can access it, how it's shared, and how it's kept secure.
- **Analyze** — use formulas to aggregate data or build reports, and pivot tables for clear visual summaries.
- **Archive** — keep spreadsheets you don't use often but might need later, especially useful for preserving historical data before it gets overwritten.
- **Destroy** — delete a spreadsheet once you're certain you'll never need it, if a better backup exists, or for legal/security reasons. Many companies have formal rules for when and how data must be destroyed.
